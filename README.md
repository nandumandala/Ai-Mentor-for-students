# AI Mentor — Personal Career Coach

## Features
- AI-Powered Career Coach
- Personalized Roadmap Generation
- Interactive Learning Hub
- Coding Practice Sandbox
- Resume Analysis
- Mock Interview AI

## Tech Stack
- Frontend: React + TypeScript + Vite + Tailwind CSS
- Backend: Node.js + Express + TypeScript
- Database: PostgreSQL with Prisma ORM
- AI Integration

## Getting Started

### Backend
1. `cd backend`
2. `npm install`
3. Set up `.env` based on `.env.example`
4. `npm run dev`

### Frontend
1. `cd frontend`
2. `npm install`
3. `npm run dev`
